# Jumping from fully guided to fully unguided was too big a step

Lessons 1-3 (numbered steps) felt easy. Lesson 4 (concepts + spec, hidden hints) felt "way harder". He completed it but is unsure which method actually teaches best. This matches the research: novices need explicit guidance, which should *fade gradually* as skill grows (Clark, Kirschner & Sweller 2012, "expertise reversal effect"). Easy practice also overstates how much has been learned (Bjork's desirable difficulties).

**Implications**: From L5, use faded guidance. A worked example for the genuinely new concept, then a completion task (partial code with TODOs), then a small independent challenge built from *already known* concepts. Calibrate using which L4 hints he needed (asked; pending).
