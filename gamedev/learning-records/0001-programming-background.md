# Already a professional C and Python programmer; no art experience

The learner writes C and Python daily as an embedded software engineer. Don't teach variables, loops, functions or debugging. Teach Godot's model (nodes, scenes, signals, the game loop) and use Python/C comparisons. He has never used any art or 3D tool, so Blender starts from zero, and 3D concepts (transforms, cameras, lighting, meshes) need explaining from scratch.

**Implications**: GDScript syntax can be skimmed. Lessons can move fast on code and slow on 3D space and the editor.
