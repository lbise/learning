# Mission: Making 3D games with Godot (and later Blender)

## Why
A creative hobby: build small 3D games I can play with my kids. If one turns out good enough, publishing on Steam would be a bonus. Not a career change. I already work as an embedded software engineer.

## Success looks like
- Finish and share a small 3D game my kids can play (one level, one clear goal)
- Model, texture and import a simple character or prop I made myself in Blender
- Build a prototype of a game in the style I like: third-person survival (Valheim) or isometric action (cyberpunk)
- Enter a game jam and submit something
- Someday, maybe: publish a game on Steam or itch.io

## Constraints
- About 3 hours per week
- Already programs in C and Python professionally (embedded): no need to teach programming basics
- Zero experience with art or 3D tools
- Linux (Arch), Godot 4.7 installed

## Out of scope
- Mobile games
- Career-level or studio production pipelines
