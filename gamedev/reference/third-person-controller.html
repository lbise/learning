Third-person controller

The rig, mouse look, camera-relative movement, facing. Built from Lesson 4.

The rig: one axis per node

Player (CharacterBody3D)  never rotated
├─ CollisionShape3D
├─ Model (Node3D)          yaw → movement dir
│  └─ meshes / imported character
└─ CameraPivot (Node3D)    yaw ← mouse X, y≈1.5
   └─ SpringArm3D          pitch ← mouse Y, length 5
      └─ Camera3D          positioned by the arm

Rotate the Model, not the body. Children inherit transforms.

Mouse look

Input.mouse_mode = Input.MOUSE_MODE_CAPTURED

func _unhandled_input(event: InputEvent) -> void:
	if event is InputEventMouseMotion:
		pivot.rotation.y -= event.relative.x * sens
		arm.rotation.x = clampf(
			arm.rotation.x - event.relative.y * sens,
			deg_to_rad(-70.0), deg_to_rad(20.0))

Mouse motion is an event (relative = pixels since the last event), not a pollable state.

Input: poll vs events

Keys / actionsHave a state: poll with Input.is_action_pressed() (held) or is_action_just_pressed() (edge)
Mouse motionDelta reports, like encoder ticks: receive in _unhandled_input and accumulate event.relative
WheelInputEventMouseButton, button_index == MOUSE_BUTTON_WHEEL_UP / _DOWN
Event order_input → GUI → _unhandled_input. Gameplay goes in the last one
Unitssensitivity = rad/pixel. 100 px × 0.003 = 0.3 rad ≈ 17°

Gotchas

Camera clips into wallsUse SpringArm3D, with the camera as a direct child
Arm too shortspring_length defaults to 1 m
Model snaps back when idleOnly update the facing while moving
Character walks backwards+Z vs −Z front: rotate the mesh 180° under Model
Esc doesn't free the mouseHandle ui_cancel → MOUSE_MODE_VISIBLE
