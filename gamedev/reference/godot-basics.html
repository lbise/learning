Godot basics

The model, the loop, 3D conventions, and shortcuts. Built from Lesson 1.

The model

ConceptWhat it is
NodeOne building block with one job (draw a mesh, render a view, emit light).
SceneA saved tree of nodes (.tscn). Reusable, like a prefab. Scenes nest inside scenes.
Scene treeAll running scenes joined into one tree at runtime.
ScriptA class attached to a node. extends names the node type.

Children inherit their parent's transform: move or rotate the parent and the children follow.

Source: Key concepts overview

The game loop

CallbackWhen
_ready()Once, when the node enters the scene tree
_process(delta)Every rendered frame. Frame rate varies.
_physics_process(delta)Fixed rate, 60/s by default. Use for movement that collides.

delta = seconds since the last call. Always multiply speeds by delta.

Source: Idle and Physics Processing

3D conventions

Up+Y (Blender uses +Z: watch for this when importing)
ForwardVector3.FORWARD = (0, 0, -1)
Units1 unit = 1 metre
AnglesRadians in code (full turn = TAU ≈ 6.28). Degrees in the Inspector. deg_to_rad() converts.
positionRelative to the parent. global_position is relative to the world.
ImportglTF 2.0 (.glb/.gltf) is the recommended format

Snippets

# Expose a tunable value in the Inspector
@export var speed := 3.0

# Spin around Y, frame-rate independent
rotate_y(spin_speed * delta)

# Arrow/WASD/stick → ground-plane movement
var v := Input.get_vector("ui_left", "ui_right", "ui_up", "ui_down")
position += Vector3(v.x, 0, v.y) * speed * delta

# Single action check
if Input.is_action_pressed("ui_accept"):
	pass

get_vector caps the length at 1, so diagonals aren't faster. Input reference
