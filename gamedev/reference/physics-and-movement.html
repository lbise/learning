Character controller

extends CharacterBody3D

@export var speed := 5.0
@export var jump_velocity := 4.5

func _physics_process(delta: float) -> void:
	if not is_on_floor():
		velocity += get_gravity() * delta   # accel → vel: × delta
	if Input.is_action_just_pressed("jump") and is_on_floor():
		velocity.y = jump_velocity
	var input := Input.get_vector("move_left", "move_right",
			"move_forward", "move_back")
	velocity.x = input.x * speed
	velocity.z = input.y * speed
	move_and_slide()                        # vel → pos: delta applied inside

Sources: CharacterBody3D, PhysicsBody3D.get_gravity

Rules of thumb

Movement code_physics_process (fixed 60 Hz by default)
velocitym/s. Never pre-multiply by delta
is_on_floor()Result of the last move_and_slide()
is_action_just_pressedTrue on one tick only, for one-shot actions (jump, shoot)
is_action_pressedTrue while held, for continuous actions (sprint)
Input actionsProject Settings → Input Map. Name actions by intent (jump), not by key
Scene instancesEdit the .tscn and every instance updates

Jump maths

Peak heighth = v² / 2g
Velocity for heightv = √(2gh)
Time to peakt = v / g
Default g9.8 m/s²

Measured in 4.7: v = 4.5 → about 1.07 m (the analytic value is 1.03). Discrete 60 Hz steps overshoot slightly.
