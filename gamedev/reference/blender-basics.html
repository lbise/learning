Create & transform

Shift+AAdd menu (Mesh → Cube, Cylinder, Cone…)
F9 / bottom-left panelAdjust Last Operation: size, vertices… (only right after adding)
G / R / SMove / rotate / scale
then X Y ZLock to an axis (Shift+axis = exclude that axis)
then a number, EnterExact amount. RMB / Esc cancels
X / DeleteDelete selected

Grammar: verb → axis → amount → confirm. G Z 0.75 Enter.

Exact size: Sidebar (N) → Item → Dimensions, typed with units (5m, 50cm), then Ctrl+A → Scale. Typing Dimensions sets the object's scale, so always apply it afterwards. Dimensions are in the object's local axes and cover the whole object. Alternative: resize in Edit Mode (S X new/old), which never touches the scale.

Source: Axis locking, Adjust Last Operation

Game-ready habits (so far)

  • Model in real metres: coin r 0.4 m, character about 1.8 m, crate 1 m.
  • Low vertex counts (8–24 sides) give a clean low-poly look.
  • Name objects and materials in the Outliner. The names show up in Godot.
  • Keep materials to Base Color, Metallic and Roughness until you learn textures.
