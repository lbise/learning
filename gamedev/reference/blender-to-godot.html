Blender → Godot pipeline

The checklist for every prop. Built from Lesson 9.

Before export (Blender)

1. One objectSelect the parts, active one last → Ctrl+J (keeps the active object's origin)
2. Origin at the baseShift+S → Cursor to World Origin, then Object → Set Origin → Origin to 3D Cursor
3. At world originAlt+G (clear location)
3½. Modifiers first!Deform modifiers (Simple Deform, Mirror…) use the object's transform. Apply them before transforms: modifier ˅ → Apply, or Object → Convert → Mesh. Otherwise the shape gets mangled
4. Clean transformsCtrl+A → All Transforms (rotation 0, scale 1)
5. NamesObject and material names carry over to Godot

Sources: manual, Join, Origin, Clear, Apply

Export settings

MenuFile → Export → glTF 2.0
Format.glb (one binary file)
Include → Limit toSelected Objects ✔
Transform+Y Up ✔ (default)
Data → MeshApply Modifiers ✔ whenever you use modifiers (Mirror…). It's off by default
Destination<godot project>/models/name.glb. Re-export over it to update

Source: glTF 2.0 add-on

In Godot

Tree (StaticBody3D)           ← your scene: physics
├─ tree (tree.glb instance)     ← visuals, no transform
└─ CollisionShape3D             ← sized via its shape, never scaled
ImportAutomatic when the file appears or changes
MaterialsPrincipled BSDF Base Color / Metallic / Roughness → StandardMaterial3D
VarietyRotate freely. For size, model a variant or resize the shape, never scale the body
ShortcutsDirect .blend import (needs Blender installed). The -col name suffix auto-generates a trimesh collision

Sources: Available 3D formats, Node type customization

Moving parts (Lesson 11)

Own objectEdit Mode: select it (X-ray Alt+Z, Shift+L deselects a linked part) → P Selection
Close holesSelect → Select All by Trait → Non Manifold, then F
Origin on the pivotSelect the hinge edge → Shift+S Cursor to Selected → Set Origin → Origin to 3D Cursor
Don't apply locationThat moves the origin back to the world origin and loses the hinge
Test in BlenderR X -110, then Esc
X rotationsCarry over to Godot unchanged (the +Y Up conversion is itself a rotation about X)

Non-destructive: import the .blend directly

Setup (once)Editor Settings → Filesystem → Import → Blender → Blender Path = ~/.local/opt/blender-5.2.2-linux-x64/blender
WhereKeep the .blend inside the Godot project (e.g. models/)
Import dock (per file)Blender → Nodes: Visible = Visible Only (skips hidden Spares), untick Cameras and Punctual Lights → Reimport
ResultModifiers applied at import, so the .blend stays live. Each object becomes its own node, with transforms kept on the nodes
IterateEdit in Blender, Ctrl+S, and Godot reimports

Prefer .glb? Bake a copy (an Export collection), never your working objects.

Source: Available 3D formats → Importing .blend files directly. Tested in 4.7.2 + Blender 5.2.2: by default, hidden objects and lights are imported.
