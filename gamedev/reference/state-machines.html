State machines

Enum + match character controller with one-shot animations. Built from Lesson 7.

The pattern

enum State {…} + var stateSingle source of truth
match state: in _physics_processPer-tick behaviour + exit conditions
change_state(new)The only writer of state. Guard against same-state, then run enter actions once
animation_finishedExit trigger for one-shot states. Check state in the handler

Smell that calls for this pattern: several booleans where only one should be true.

Source: Game Programming Patterns: State

Skeleton

enum State { IDLE, MOVE, AIR, LAND, ROLL, CELEBRATE }
var state := State.IDLE

func _physics_process(delta: float) -> void:
	# shared: gravity, read input
	match state:
		State.IDLE, State.MOVE:
			# walk; check jump / roll / fall / move
		State.AIR:
			if is_on_floor(): change_state(State.LAND)
		State.LAND:
			# cancel into MOVE on input
		State.ROLL:
			# fixed direction, no steering
	move_and_slide()

func change_state(new_state: State) -> void:
	if new_state == state:
		return
	state = new_state
	match state:
		State.LAND: anim.play("Jump_Land", 0.1, 2.0)
		# …

func _on_animation_finished(_name: StringName) -> void:
	if state in [State.LAND, State.ROLL]:
		change_state(State.IDLE)

Facts and gotchas

play(name, blend, speed)The 3rd argument is the playback speed (2.0 = twice as fast)
animation_finishedNever emitted for looping clips
Facing direction-model.global_basis.z (Model −Z faces the movement)
First tickis_on_floor() is false until the first move_and_slide()
Commit movesStore the direction in the enter action (a roll ignores steering)
Game feelMake long one-shots cancellable (LAND → MOVE on input)
