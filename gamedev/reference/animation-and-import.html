Animation & import

Bringing in glTF characters and driving an AnimationPlayer. Built from Lesson 6.

Importing a character

FormatglTF 2.0 (.glb) is recommended. Drop it in the project and it imports automatically
UseInstance it like any scene: drag it onto Model
FacingAssets face +Z (MODEL_FRONT). Rotate the instance 180° under Model
Preview clipsDouble-click the .glb to open Advanced Import Settings
LoopingClip names containing the token loop/cycle import looping, with the token stripped (Walk_Loop → Walk)
Root motionUse clips without root motion with a CharacterBody3D: your code moves the body

Sources: Node type customization, Import configuration, Vector3

AnimationPlayer

@onready var anim: AnimationPlayer = $Model/Character/AnimationPlayer

func update_animation(dir: Vector3, sprinting: bool) -> void:
	if not is_on_floor():
		anim.play("Jump", anim_blend)
	elif dir.length() > 0.01:
		anim.play("Sprint" if sprinting else "Walk", anim_blend)
	else:
		anim.play("Idle", anim_blend)
play(name, blend)blend = cross-fade seconds (−1 uses the default)
Same clip againContinues, doesn't restart. Safe to call every tick
Finished one-shot clipplay() again restarts it
List clipsanim.get_animation_list()
Blend feel0.1–0.25 s is usually right

Source: AnimationPlayer. The continue and restart behaviour was tested in 4.7.2.
